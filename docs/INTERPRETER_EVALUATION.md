# Interpreter evaluation

Generated by `npm run eval:interpreters -- --write` on 2026-10-22, with the model `qwen2.5:3b-instruct` served at localhost:11434 with a timeout of 30000 ms. Rerun it to reproduce; the rules interpreter's numbers are deterministic, the model's may vary between runs and model versions.

30 customer messages, labelled by hand before either interpreter was run on them (data/evaluation/interpreter-paraphrases.json). Each field is scored separately:

- **goal**: return, exchange or not stated.
- **reason**: defective, changed mind, or not stated.
- **product**: the extracted product query finds exactly the labelled order in the fictional sandbox (or no product is extracted when none is named).
- **time hint**: a purchase time is picked up when, and only when, the message states one.

Serial and order numbers are not scored: they always come from the rules interpreter. The model assisted reading uses the model for goal, reason, product, issue description and purchase time, and the rules interpreter for everything else. When the model fails (invalid output, HTTP error, timeout), the service uses the rules reading, and so does this score.

## Limitations

- 30 messages, written and labelled by the same team that built the interpreters. They are a check of field extraction on plausible phrasings, not a measurement of real customer language.
- Some labels are judgement calls (for example, whether discomfort is a change of mind). They were fixed before any run and are not changed after.
- A reason is a customer claim, but it selects the policy rule, and so the shipping terms of the proposed return. In this run the model supplied a reason the customer did not state on 2 message(s) (P02, P23). The proposed terms, including the reason, are shown to the customer before approval, but a wrong reason is still a real risk of using a model here.
- Better reading does not change what AFTERCARE may do. Every decision still comes from the compiler, and every identifier still comes from the customer's own text.
